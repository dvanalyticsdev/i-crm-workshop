Setup Guide

Configure Elementor to POST directly into this CRM endpoint.

1
Use the Webhook action in Elementor
In your Elementor form, add the Webhook action and paste the Webhook URL from this page.
2
Send stable form identifiers
Keep form_id and form_name stable. The CRM will use them to decide whether a lead is a workshop or main-admission lead.
3
Add explicit lead-type hints when possible
If you can, include hidden fields such as lead_type, intent, or a distinctive page URL. This makes classification safer than relying on fuzzy text alone.
4
Save rules and enable
Add your allow-list and routing rules below, save them, then enable the integration.
